## modlAMP 4.3.0

This repository includes unmodified local copies of the modlAMP 4.3.0 modules required for global descriptor calculation (`__init__.py`, `version.py`, `core.py`, and `descriptors.py`). These modules are included locally because the package's historical metadata requires an unavailable MySQL connector that is unrelated to descriptor calculation. The application uses `modlamp.descriptors.GlobalDescriptor`.
